## Examples

Larger, complete programs -- as opposed to the single-feature [tutorials](../tutorials/index.md) -- each demonstrating BASCAL at a bigger scale, or porting/adapting a real pre-existing program.

- [Sort Driver](sort-driver.md) -- recursive `require`, array argument passing, and timing across bubble, shaker, shell, and quick sort.
- [REMLINE](remline.md) -- analyses a line-numbered BASIC program and removes unnecessary line numbers while preserving real jump targets.
- [Card Catalog](card-catalog.md) -- the flagship [record/file DSL](../manual/record-files.md) application, adapted from a 1983 BASIC program.
- [Adventure Game](adventure.md) -- a from-scratch Delphi-to-BASCAL port used as a language-design case study for BASCAL's planned record model.
- [ADVENTURE/3000 Port](adventure3000.md) -- a staged port of a large 1979 HP/3000 BASIC text adventure, six stages from unmodified original to fully structured BASCAL.
