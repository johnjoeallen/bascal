Chapter 3

Making control flow visible

Blocks replace branch plumbing

A program is easier to change when its source shows where an alternative or repetition begins and ends. BASCAL’s block forms do that while retaining BASIC’s familiar vocabulary.

for row% = 1 to 10
    if row% mod 2 = 0 then
        print "even";
    else
        print "odd";
    end if
    print row%
end for

if, elseif, else, and end if make a selection one unit. for, while, and do make repetition one unit. The target BASIC still uses its branches, but they are generated from the structure rather than maintained by hand.

Choose among many cases

select case score%
case 90 to 100
    grade$ = "A"
case is >= 80
    grade$ = "B"
case else
    grade$ = "C"
end select

select case is particularly useful when a ladder of conditions is really one decision. Use && and || when a later condition must only be evaluated when needed. The complete treatment of block forms also covers early exits and pre- and post-condition do loops.
