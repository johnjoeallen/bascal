Chapter 5

Data that outlives a run

Describe the data first

For fixed-size random-access data, BASCAL lets you express the record layout in the program. The compiler takes care of the target’s FIELD, conversion, and GET/PUT sequence.

record Student
    id:    int16
    name:  string(20)
    score: float64
end record

file students as Student = open("students.dat")
students[1] = { id: 1, name: "Ada", score: 98.5 }

The source says that a file contains students and that the first student has three named fields. It does not ask you to repeat field offsets and buffer assignments at every write.

Keep the target available

BASCAL remains a strict superset of the target dialect. Existing sequential file operations and hand-written BASIC file statements can pass through when you need them. In new source, prefer the structured record/file form when it describes the job: it is clearer and protects the layout from drifting apart. Record files support partial updates, reads, field assignment, and explicit closing as well as full record writes.
