Chapter 1

A first program

Start with the whole

BASCAL is written in .bcl files. The compiler, bcc, can turn one into ordinary classic BASIC or C. The target is an implementation detail while you are writing: begin by describing the work in the order a reader expects to see it.

dim name$

print "What is your name";
input name$

if name$ = "" then
    print "Hello, stranger."
else
    print "Hello, " + name$ + "."
end if

Save this as hello.bcl and run bcc hello.bcl. The default backend creates hello.bas; bcc --target c hello.bcl emits C instead. The C backend is experimental and supports a narrower part of the language than the BASIC backend.

Read it from top to bottom

dim name$ declares a string variable. print and input are familiar BASIC operations. The important difference arrives at the decision: the if has a visible beginning, alternatives, and an end if. There are no numbered exits to hunt down.

BASCAL gives control flow a source-level shape that is easy to read, then emits the necessary constructs for the selected target.

The next chapters unpack the declaration, expression, and block syntax used here. Later chapters provide the detailed rules for the language and its command line.
