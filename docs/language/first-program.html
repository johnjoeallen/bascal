Chapter 1

A first program

Start with the whole

BASCAL files use the .bcl file extension. The compiler, bcc, can turn one into ordinary classic BASIC or C. The target is an implementation detail while you are writing: begin by describing the work in the order a reader expects to see it.

program hello

dim name$

print "What is your name";
input name$

if name$ = "" then
    print "Hello, stranger."
else
    print "Hello, " + name$ + "."
end if
end

Save this as hello.bcl and run bcc hello.bcl. The default backend creates hello.bas; bcc --target c hello.bcl emits C instead — this example compiles under both, but some source doesn’t yet, since --target c is experimental and still covers a narrower part of the language than the BASIC backend (see the Backends section of the manual for exactly what’s covered so far).

Every file declares what it is

program hello is not optional dressing: every .bcl file must open by declaring exactly what it is — a runnable program <name> like this one, a library <name> that only require loads (see Functions, procedures, and libraries), or a shared <name> file of nothing but variable declarations (see Running and combining programs). bcc refuses to compile a root file missing this header, rather than guessing. A trailing bare end closes the program the same way it closes a select case or for — the compiler could technically infer it from end-of-file, but writing it keeps every program’s shape consistent.

From here on, most examples in this book are shown as fragments — the interesting handful of lines, without program name or the trailing end wrapped around them — the same way a math book shows a formula without re-deriving arithmetic first. Add both when you turn a fragment into a file you actually compile.

Read it from top to bottom

dim name$ declares a string variable. print and input are familiar BASIC operations. The important difference arrives at the decision: the if has a visible beginning, alternatives, and an end if. There are no numbered exits to hunt down.

BASCAL gives control flow a source-level shape that is easy to read, then emits the necessary constructs for the selected target.

The next chapters unpack the declaration, expression, and block syntax used here. Later chapters provide the detailed rules for the language and its command line.
