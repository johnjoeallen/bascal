The BASCAL Programming Language

A programmer’s introduction to BASCAL: a clear, structured superset of BASIC inspired primarily by Pascal.

An online book for BASCAL 0.99

This is the complete reference for BASCAL. Read it from the beginning to build the language up through complete programs, then return to its chapters whenever you need a precise rule or example.

Part I · The language

The core ideas needed to read and write a BASCAL program.

  1. 01A first programCompile, run, and read a complete BASCAL program before learning its individual pieces.
  2. 02Values, names, and expressionsBASIC type suffixes, declarations, constants, arrays, and the expressions that connect them.
  3. 03Making control flow visibleUse blocks, loops, and selection instead of wiring a program together with line numbers.
  4. 04Arrays and stringsDeclare fixed collections, pass them deliberately with byref/byval, and work with text through BASIC's string functions.

Part II · Building programs

Ways to grow beyond a single page without losing the simplicity of BASIC.

  1. 05Functions, procedures, and methodsGive operations names, pass data deliberately, and declare typed scalar methods you can chain.
  2. 05ALibrariesReuse code across files, and across functions, procedures, and methods, through require.
  3. 06Data that outlives a runWork with sequential input and output, then let typed records remove random-file bookkeeping.
  4. 07Errors, labels, and embedded dataHandle runtime errors with on error goto, reach for a label when structure genuinely can't reach, and ship constant tables with data/read.
  5. 08The standard libraryThe built-in math, string, and conversion functions every BASCAL program can already call.
  6. 09Running and combining programsbcc's command line, and linking separately-run programs together with shared/COMMON/CHAIN.
  7. 10The targets beneath the programUnderstand the BASIC and C targets without programming at either level every day.
