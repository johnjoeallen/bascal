Preface

A language for writing BASIC more clearly

BASCAL begins with a simple observation: classic BASIC has an immediate, practical character, but programs become difficult to hold in the mind when their structure is carried by line numbers and jumps. BASCAL keeps the familiar data model, statements, and straightforward deployment of BASIC while giving the source program a clearer shape.

It is a structured superset of BASIC, inspired primarily by Pascal. Blocks make alternatives and repetition visible. Functions and procedures give work names. require gives source files a proper path-based dependency mechanism, inspired by Java. A required library is resolved by path and incorporated into the generated program. Typed record declarations let a program state the shape of persistent data rather than repeatedly manage its byte-level representation.

The source and its targets

BASCAL source lives in .bcl files. The complete default backend turns them into line-numbered Microsoft BASIC; an experimental C backend is also available with --target c. This is not an attempt to hide the target language. BASCAL is designed so that generated output can still be read, inspected, and compiled by the toolchain appropriate to the target.

The normal advice is nevertheless simple: write BASCAL when BASCAL has a construct for the job. Use structured if and loops instead of hand-wiring jumps, and use record/file rather than reproducing the bookkeeping of random-access files. Raw BASIC remains useful where a program genuinely needs target-specific behaviour.

Who should read this book

This book is for programmers who want to learn BASCAL as a language, whether they already know BASIC, are returning to it, or simply enjoy working with a small language and a visible compilation target. It assumes only that you can read a program and are willing to run short examples. Familiarity with Pascal is useful, but not required.

How to use this book

Read the first part in order. Each chapter starts from an idea in a complete program and adds only the detail needed to use it well. The later chapters provide the full syntax rules, semantic details, and command-line information, so the book remains the single authoritative source for the language.

This book explains how to think in BASCAL and defines exactly what each form means.

The best way to proceed is to compile and alter the small programs as you read. BASCAL’s generated code is available for inspection, but the program you maintain should remain the clear, structured source.
