Scalar methods

Declare and call a method

A scalar method declaration names its receiver type with the suffix on method. The method name carries its result suffix, and the receiver is available as the matching implicit self value.

method$ capitalize$()
    return UCASE$(self$)
end method

name$ = "ada"
result$ = name$.capitalize()

Calls always use parentheses. Calls can chain when the previous result has the receiver type required by the next method:

result$ = name$.capitalize().pad(20)

Methods from libraries

Declare the library with require, then use its methods through the same receiver syntax. A required library’s methods participate in the same compile-time receiver and result-type checks as methods declared in the program.

require com.example.text

result$ = name$.capitalize()

The parser and resolver support this front end. The BASIC target lowers calls through its ordinary global-parameter/GOSUB model, while the C target emits typed calls and result temporaries.
