Chapter 10

The targets beneath the program

One source language, two targets

BASCAL has two code generators. Its complete, default backend transpiles to line-numbered Microsoft BASIC; --target c emits C. Each target is a useful constraint, not a disguise: generated output can be inspected and compiled by the toolchain that owns it.

The C backend is experimental and has a narrower supported surface than the BASIC backend. Choose it when its supported features meet the program’s needs; its supported constructs and command-line options are specified in this book.

At the same time, BASCAL source should normally use BASCAL’s structured constructs. A block if is preferable to a hand-wired GOTO ladder for the same reason a function is preferable to copying its body: it retains the intent at the place where the program is maintained.

See it happen

A block if and a while loop compile to exactly the branch-and-jump shape they would have taken if you had wired them by hand — the compiler is just the one holding the pen.

if n% > 3 then
    print "big"
else
    print "small"
end if

while n% > 0
    print n%
    n% = n% - 1
end while

transpiles to:

50 IF (n% > 3) = 0 THEN GOTO 80
60     PRINT "big"
70     GOTO 90
80     PRINT "small"
90 REM END IF

100 IF (n% > 0) = 0 THEN GOTO 140
110     PRINT n%
120     n% = n% - 1
130     GOTO 100
140 REM END WHILE

An if/else becomes an inverted test that jumps past the then branch when the condition is false, with the then branch itself ending in a jump past the else; a while is the same inverted test repeated at the top of a loop, with the last line jumping back up to it. REM END IF/REM END WHILE are just comments — real BASIC needs no closing statement here, but the compiler leaves a marker anyway, so the generated source stays readable on its own. Nothing about this shape is unusual or BASCAL-specific; it is what any programmer comfortable with classic BASIC would have written by hand for the same logic, indentation included.

When raw BASIC matters

Some classic statements are intentionally available when a program needs the BASIC target’s particular behavior. Labels let raw GOTO, GOSUB, RESTORE, and error handling name a destination without exposing a numeric line number — the compiler owns those numbers instead; see Errors, labels, and embedded data for the complete forms.

Think in BASCAL; inspect the generated BASIC or C when target behavior matters. The source is where you design, while the target is where you verify compatibility and reach platform-specific facilities.

One complete book

This book is both an introduction and the authoritative BASCAL reference. Read it in order to learn the language, then return to the relevant chapter for its complete syntax, semantics, and examples. It is organised to make the language readable without separating learning from the rules that define it.
