04. Conditions

Multiline if / elseif / else / end if, plus single-line if...then, transpiled to numbered GOTO targets for you.

Home Manual Tutorials GitHub

Home / Tutorials / Conditions

BASCAL supports multi-line block if statements: if cond then ... end if, with optional else and any number of elseif clauses. It also supports classic BASIC's single-line form — a statement directly after then on the same line needs no end if at all. A newline right after then is what selects the block form instead; that's the only difference. The compiler transpiles either form to numeric GOTO targets in the generated BASIC — you never write a line number yourself.

if / elseif / elseif / else

if points% >= 90 then
    grade$ = "A"
elseif points% >= 80 then
    grade$ = "B"        // points% = 85 lands here
elseif points% >= 70 then
    grade$ = "C"
elseif points% >= 60 then
    grade$ = "D"
else
    grade$ = "F"
end if

Single-line if — no end if needed

elseif isn't available single-line, same as classic BASIC — it needs the block form above.

if temperature% > 30 then print "Hot day (single-line)"
if temperature% > 100 then print "Scorching" else print "Not scorching"
