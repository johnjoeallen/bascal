04. Conditions

Multiline if / elseif / else / end if, lowered to numbered GOTO targets for you.

Home Manual Tutorials GitHub

Home / Tutorials / Conditions

BASCAL supports multi-line block if statements: if cond then ... end if, with optional else and any number of elseif clauses. The compiler lowers these to numeric GOTO targets in the generated BASIC — you never write a line number yourself.

if / elseif / elseif / else

if points% >= 90 then
    grade$ = "A"
elseif points% >= 80 then
    grade$ = "B"        // points% = 85 lands here
elseif points% >= 70 then
    grade$ = "C"
elseif points% >= 60 then
    grade$ = "D"
else
    grade$ = "F"
end if

Full, real, compiling source: tutorial/04_conditions.bcl, tutorial/04_conditions.bas.
