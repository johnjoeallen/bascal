05. Loops

for/next, while/wend, and do/loop, each with an early-exit statement.

Home Manual Tutorials GitHub

Home / Tutorials / Loops

BASCAL has three loop constructs: counted for ... to [step n] ... end for, pre-check while ... end while, and do, which comes in two forms — do [while/until cond] ... end do tests the condition at the top (may run zero times), and do ... loop [while/until cond] tests it at the bottom (always runs at least once — BASCAL's direct repeat/until equivalent). Each loop has a matching early-exit statement. See the control-flow comparison on the homepage for what each one compiles down to.

for / next with an early exit

for i% = 1 to 20
    if i% > 4 and (i% / 2) * 2 = i% then
        print "  "; i%
        exit for
    end if
end for

DO WHILE and DO UNTIL

Two spellings of the same pre-check loop shape.

do while k% <= 3
    print "  "; k%
    k% = k% + 1
end do

do until k% > 3
    print "  "; k%
    k% = k% + 1
end do

DO ... LOOP UNTIL — post-check, body runs at least once

The condition is tested after the body, not before, so this prints once even though k% starts already past the stopping value.

k% = 99
do
    print "  "; k%
    k% = k% + 1
loop until k% > 3
