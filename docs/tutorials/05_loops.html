05. Loops

for/next, while/wend, and do/loop, each with an early-exit statement.

Home Manual Tutorials GitHub

Home / Tutorials / Loops

BASCAL has three loop constructs: counted for ... to [step n] ... end for, pre-check while ... end while, and do [while/until cond] ... end do (condition at the top, or a bare do with a manual exit do for a post-check loop). Each has a matching early-exit statement. See the control-flow comparison on the homepage for what each one compiles down to.

for / next with an early exit

for i% = 1 to 20
    if i% > 4 and (i% / 2) * 2 = i% then
        print "  "; i%
        exit for
    end if
end for

DO WHILE and DO UNTIL

Two spellings of the same pre-check loop shape.

do while k% <= 3
    print "  "; k%
    k% = k% + 1
end do

do until k% > 3
    print "  "; k%
    k% = k% + 1
end do
