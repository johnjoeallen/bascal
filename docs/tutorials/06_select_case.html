06. Select Case

One expression, evaluated once, tested against exact values, lists, ranges, and IS comparisons.

Home Manual Tutorials GitHub

Home / Tutorials / Select Case

select case evaluates its expression once, stores it in a compiler- generated temporary, and dispatches against each case clause in order. Patterns can be an exact value, a comma-separated list, an inclusive lo to hi range, or an is <op> value comparison; case else is the default and must come last. See the control-flow comparison on the homepage for the GOTO dispatch chain this compiles to.

IS comparisons

select case temp%
case is < 0
    print "Below freezing ("; temp%; "deg)"
case is < 10
    print "Cold ("; temp%; "deg)"
case is < 20
    print "Cool ("; temp%; "deg)"
case else
    print "Hot ("; temp%; "deg)"
end select

Full, real, compiling source: tutorial/06_select_case.bcl, tutorial/06_select_case.bas.
