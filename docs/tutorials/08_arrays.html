08. Arrays

dim for 1-D and N-D arrays, and passing them into functions.

Home Manual Tutorials GitHub

Home / Tutorials / Arrays

dim name%(size) declares a 1-D array of size + 1 elements, indexed 0..size; dim name%(rows, cols) declares a 2-D array, and more dimensions are allowed. To pass an array into a function, the parameter is just the plain variable name (arr%, not arr%()); at the call site you write arr%() to signal that an array is being passed.

Insertion sort, in place

function insertionSort%(arr%, count%)
    for i% = 1 to count% - 1
        key% = arr%(i%)
        j%   = i% - 1
        while j% >= 0 and arr%(j%) > key%
            arr%(j% + 1) = arr%(j%)
            j% = j% - 1
        end while
        arr%(j% + 1) = key%
    end for
    return 0
end function

Calling it, and a 2-D array

dim data%(N%)
' ... populate data%(0..N%-1) ...
dummy% = insertionSort%(data%(), N%)

dim identity%(2, 2)
identity%(1, 1) = 1
