13. Suite COMMON

A shared COMMON block, declared once, emitted verbatim into every program that joins the suite.

Home Manual Tutorials GitHub

Home / Tutorials / Suite COMMON

Classic multi-program BASIC systems pass shared variables across a CHAIN with COMMON — every chained program has to declare an identical COMMON list, or values land in the wrong slots. A BASCAL suite file contains only variable declarations; any program that opens with program name suite suitename gets that suite's declarations emitted verbatim at the top of its generated output, so two programs can't drift out of sync by hand.

The suite file

suite <name> declares this file as the suite itself (mirroring a regular file's program <name>), and each dim below becomes one shared variable -- no statements, no functions. The older headerless common count%, label$ spelling still works too.

suite shared

dim count%
dim label$

A program that joins the suite

program start suite shared

count% = count% + 1
count% = count% + 1
count% = count% + 1

' In a real multi-program application: CHAIN "show.bas"
tutorial/13_suite/shared.bcl 
/*
 * Suite file for Tutorial 13 — COMMON / CHAIN.
 *
 * `suite shared` declares this file as the suite itself, named `shared`
 * (matching this filename, shared.bcl). Every program that begins with
 * "program name suite shared" receives an identical COMMON block at the
 * top of its generated BASIC, built from the `dim` declarations below --
 * so the listed variables are shared across CHAINed programs in a
 * multi-program application.
 *
 * (The older spelling -- no `suite` header, just `common count%, label$`,
 * with the suite name taken from the filename alone -- still works too.)
 *
 * This suite shares a counter and a label between two programs:
 *   start.bcl  — initialises and increments the counter
 *   show.bcl   — reports the final value
 */
suite shared

dim count%
dim label$
tutorial/13_suite/start.bcl 
// Tutorial 13 — Suite COMMON, program 1 of 2
//
// "program name suite suitename" tells bcc to load suitename.bcl and
// emit its COMMON declarations at the very top of the generated output.
// All programs in the same suite emit the same COMMON block, so the
// variables survive a CHAIN to the next program.
//
// Compile:
//   bcc tutorial/13_suite/start.bcl
//
// The generated .bas will open with COMMON count%, label$ followed by
// the program body below.

program start suite shared

label$ = "Counter demo"
count% = 0

count% = count% + 1
count% = count% + 1
count% = count% + 1

print "Initialised: " + label$
print "Count after 3 increments: " + str$(count%)

/* In a real multi-program application you would chain to show.bas: */
/* CHAIN "show.bas" */
end
tutorial/13_suite/show.bcl 
// Tutorial 13 — Suite COMMON, program 2 of 2
//
// This program shares the same suite as start.bcl.  Its generated BASIC
// will begin with the same COMMON block, so count% and label$ contain
// whatever values start.bas left in them when it CHAINed here.
//
// Compile:
//   bcc tutorial/13_suite/show.bcl

program show suite shared

print "Label:  " + label$
print "Count:  " + str$(count%)

if count% > 0 then
    print "Counter was incremented " + str$(count%) + " time(s)."
else
    print "Counter was never incremented."
end if

end
