13. Suite COMMON

A shared COMMON block, declared once, emitted verbatim into every program that joins the suite.

Home Manual Tutorials GitHub

Home / Tutorials / Suite COMMON

Classic multi-program BASIC systems pass shared variables across a CHAIN with COMMON — every chained program has to declare an identical COMMON list, or values land in the wrong slots. A BASCAL suite file contains only variable declarations; any program that opens with program name suite suitename gets that suite's declarations emitted verbatim at the top of its generated output, so two programs can't drift out of sync by hand.

The suite file

suite <name> declares this file as the suite itself (mirroring a regular file's program <name>), and each dim below becomes one shared variable -- no statements, no functions. The older headerless common count%, label$ spelling still works too.

suite shared

dim count%
dim label$

A program that joins the suite

program start suite shared

count% = count% + 1
count% = count% + 1
count% = count% + 1

' In a real multi-program application: CHAIN "show.bas"

Full, real, compiling source: tutorial/13_suite/shared.bcl, tutorial/13_suite/start.bcl, tutorial/13_suite/show.bcl.
