15. Random-Access and Record Files

Classic FIELD/GET/PUT file I/O, and the record/file syntax that generates it for you.

Home Manual Tutorials GitHub

Home / Tutorials / Random-Access and Record Files

This tutorial writes one program twice: first with classic random-access primitives (OPEN ... FOR RANDOM, FIELD, GET/PUT, LSET, MKx/CVx), then again with BASCAL's typed record/file syntax, which generates exactly that primitive code for you. The full seven-way, side-by-side breakdown — including the ?{ ... } partial-write syntax and why it's spelled that way — lives on the homepage; this page just shows where the two halves of the file meet.

Declaring the record shape

Replaces a hand-computed byte width and a matching FIELD statement.

record Student
    id:    int16
    name:  string(20)
    score: float64
end record

file db as Student = open("students.dat")

A partial update, still one GET and one PUT

See the homepage for why this is spelled ?{ ... }.

db[1] = ?{ name: "Alice Smith", score: 91.0 }

Full, real, compiling source: tutorial/15_random_and_record_files.bcl, tutorial/15_random_and_record_files.bas.
